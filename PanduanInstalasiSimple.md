# 📱 PANDUAN INSTALASI SIMPLE - SISTEM HANDPHONE ROBLOX

## 🎯 INSTALASI SUPER SIMPLE (HANYA 2 LANGKAH!)

### ✅ **LANGKAH 1: SERVER SCRIPT**
1. Buka **Roblox Studio**
2. Buka game/place Anda
3. **Klik kanan** pada `ServerScriptService`
4. **Insert Object** → **Script**
5. **Rename** script menjadi `PhoneSystemServer`
6. **Copy-paste** semua isi file `PhoneSystem_Server.lua`
7. **Save** (Ctrl+S)

### ✅ **LANGKAH 2: CLIENT SCRIPT**
1. Buka **StarterPlayer** → **StarterPlayerScripts**
2. **Klik kanan** → **Insert Object** → **LocalScript**
3. **Rename** script menjadi `PhoneSystemClient`
4. **Copy-paste** semua isi file `PhoneSystem_Client.lua`
5. **Save** (Ctrl+S)

### ✅ **LANGKAH 3: AKTIFKAN VOICE CHAT**
1. **Klik** `Game Settings` (gear icon)
2. **Pilih** tab `Privacy`
3. **Centang** `Allow Voice Chat`
4. **Set** `Voice Chat Mode` ke `Enabled`
5. **Klik** `Save`

## 📱 **CARA MENGGUNAKAN**

1. **Buka Handphone**: Klik tombol hijau 📱 di kanan tengah layar
2. **Navigasi**: Gunakan 4 tab di bawah:
   - 🏠 **Beranda** - Menu utama
   - 👥 **Kontak** - Daftar pemain
   - 💬 **Pesan** - Chat text
   - 📞 **Panggilan** - Kontrol panggilan

3. **Panggilan**: Kontak → klik ikon telepon → tunggu jawaban
4. **Chat**: Kontak → klik ikon chat → ketik pesan
5. **Grup Call**: Beranda → Panggilan Grup → undang pemain

## 🔧 **TROUBLESHOOTING**

### **Tombol Handphone Tidak Muncul:**
- Pastikan script client ada di `StarterPlayerScripts`
- Restart game dan coba lagi
- Cek console untuk error

### **Voice Chat Tidak Bekerja:**
- Pastikan Voice Chat enabled di Game Settings
- Cek microphone permissions player
- Test dengan player lain

### **Call Tidak Terhubung:**
- Pastikan server script berjalan
- Cek RemoteEvents sudah dibuat otomatis
- Test dengan player lain
